Flexbox: flex-grow for flex items

If there is still free space along the main axis in a flex container, it is distributed to flex items with a flex-grow value greater than or equal to 1, in proportion to the flex-grow values. Elements with flex-grow: 0 do not take any additional space, and negative values are not allowed.
