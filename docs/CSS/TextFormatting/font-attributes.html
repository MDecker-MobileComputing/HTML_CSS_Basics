The difference between italic and oblique is that italic fonts are specifically designed with a unique style, while oblique fonts are simply slanted versions of the normal font. Not all fonts have a true italic version, so oblique is often used as a fallback. The browser might simulate oblique by slanting the normal font if an italic version is not available.

The keyword normal is equivalent to font-weight: 400;. The most common numeric values are 100, 200, 300, 400, 500, 600, 700, 800, and 900. In practice, 400 is normal and 700 is bold. Values such as 233 or 550 are technically valid too, but they are unusual and may be rounded or interpolated by the browser depending on the font.
