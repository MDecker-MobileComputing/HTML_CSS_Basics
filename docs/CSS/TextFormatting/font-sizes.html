Relative font sizes

Unit em

In traditional typesetting, an em was a unit equal to the point size of the type (for example, 1 em in 12-point type is 12 points), and it was historically associated with the width of the capital letter M. However, in modern web design, an em is a relative unit that is based on the font size of the direct parent element.

This is a paragraph with the font size set to 0.75em.

This is a paragraph with the font size set to 1em (which is the default in most modern browsers).

This is a paragraph with the font size set to 1.5em.

Unit %

For font-size, em and % are equivalent in value (1em = 100%, 1.5em = 150%), and both are relative to the parent element's computed font size. The main difference is mostly readability and convention: em is commonly used as a ratio, while % is often used when you want to express explicit percentages.

Unit rem

The rem unit is similar to em, but it is always relative to the font size of the root element (<html>).

Absolute font sizes

Font size in points

A point (pt) is a traditional print unit where 72 points equal 1 inch, so 12pt means 12/72 of an inch in print layout terms. For modern web interfaces on screens, pt is usually not recommended; prefer rem or em for text so sizing is more accessible and responsive to user settings.

This is a paragraph with the font size set to 9pt.

This is a paragraph with the font size set to 12pt.

This is a paragraph with the font size set to 18pt.

Font size in pixels

A pixel (px) is a unit of measurement that represents a single dot on the screen. It is an absolute unit, meaning that it does not scale based on the user's settings or the parent element's font size. While px can be useful for precise control over layout, it is generally recommended to use relative units like em or rem for text to ensure better accessibility and responsiveness.

This is a paragraph with the font size set to 12px. 12px is usually the smallest font size that is still readable on most screens, and it is often used for fine print or secondary text.
