CSS: Icons from Fontello

Fontello is an online tool that lets you create a custom icon font by selecting icons from various open-source collections. The resulting custom icon font is embedded as a web font, allowing the icons to be used like text characters and styled with CSS. An icon from this custom icon font can be added by adding a <span> element with the appropriate class name.
