A serif font is a typeface with small decorative strokes, called serifs, at the ends of letters. These extra details often make the text look more traditional, formal, and readable in long passages of print. A sans-serif font does not have these small decorative strokes; it is cleaner, more modern, and commonly used on screens and in interfaces. A monospace font uses characters that all take up the same horizontal width, which makes it useful for code and aligned text. A cursive font imitates handwriting or script styles with flowing, connected strokes and is usually decorative. A fantasy font is a highly stylized decorative typeface used for creative or playful effects rather than large amounts of readable body text.

Font Stack

A font stack is a prioritized list of fonts that the browser tries to use in order. The browser obtains the fonts from the operating system, so it checks whether the first fonts are installed, then falls back to the next ones if needed.

Web Fonts

Web fonts are fonts that are loaded from a server and used by the browser while rendering a webpage. They let designers use a wider choice of typefaces beyond the default fonts installed on the operating system.
